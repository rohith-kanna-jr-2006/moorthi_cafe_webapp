**Important Notice:** SVG assets are **illustrative graphic cards**, NOT photographs. They do not fulfill the requirement for authentic food photography.

- **Author / Origin:** Custom project vector illustrations created for Hotel New Moorthi Cafe web application.
- **Licence:** Proprietary project asset / CC BY-NC 4.0 compatible for internal demonstration.
- **Sub-Classifications:**
  1. `AUTHENTIC_ILLUSTRATIVE_ARTWORK` (48 items): Vector culinary cards with Tamil & English dish names, culinary motifs, and green authenticity badges (`AUTHENTIC CHIDAMBARAM SPECIALTY`). These serve as illustrative UI fallbacks for clear dishes pending official photo shoots.
