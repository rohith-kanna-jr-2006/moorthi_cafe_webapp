# Stitch Reference Collection for Moorthi Cafe Web App

## Overview
This directory contains the complete reference screens from Google Stitch for the Moorthi Cafe web application. All screens are organized into folders for easy navigation and implementation.

## Directory Structure

### Screens
- Each screen is stored in its own subdirectory with a descriptive name.

### Design System
- Design tokens and guidelines are stored in `design-system/design-system.json`.

## Design System

The design system includes:
- **Color Palette**: Primary `#c05621`, Secondary `#2f855a`, Tertiary `#d69e2e`, Neutral `#faf5ef`
- **Typography**: Noto Serif / Plus Jakarta Sans
- **Grid System**: 12 columns (desktop), 8 columns (tablet), 4 columns (mobile)

## Usage

1. **Verify Screens**: Ensure all screens are downloaded and accessible.
2. **Apply Design System**: Use the design tokens in your CSS and components.
3. **Implement Components**: Build UI components based on the reference screens.

## Notes

- This collection is intended for UI reference and design alignment only.
- No backend or API integration is included in these screens.
- Always validate screens against the actual design system tokens and guidelines.
